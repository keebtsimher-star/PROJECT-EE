## Design Concept

The portfolio is built around an **electrical signal / system architecture** concept.

Instead of presenting information as a traditional résumé webpage, each part of the portfolio represents a stage of an engineering system:

```text
01 // POWER ON      Introduction
        ↓
02 // PROTOTYPE     Projects
        ↓
03 // FIELD TEST    Experience
        ↓
04 // SYSTEM LOG    Achievements
        ↓
05 // COMPONENTS    Technical Toolkit
        ↓
06 // CONNECT       Contact & Resume
```

The long-term goal is to continue developing the interface with more advanced electrical and PCB-inspired interactions as my engineering experience grows.

## Running Locally

Because the current portfolio is a static HTML/CSS website, you can clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/keebtsimher-star/PROJECT-EE.git
cd PROJECT-EE
```

Then open `index.html` in your browser.
